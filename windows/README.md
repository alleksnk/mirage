# DPI Tunnel — Графический интерфейс для обхода блокировок

Лёгкое и быстрое Windows-приложение (C# / WPF) для обхода DPI и ускорения заблокированных ресурсов (**YouTube, Telegram, Discord, GitHub, торрент-трекеры вроде rutor.info**) без использования сторонних VPN.

---

## 🚀 Быстрый запуск

1. Запустите файл `DpiTunnel.exe` двойным кликом.
2. Нажмите большую кнопку **«ВКЛЮЧИТЬ ОБХОД»**.
3. Статус сменится на **зелёный «Обход DPI активен»** — сайты и сервисы начнут открываться на максимальной скорости вашего интернет-провайдера.

---

## 📌 Основные возможности

### 1. Подключение Telegram в 1 клик
* Перейдите на вкладку **«✈️ Telegram & Прокси»**.
* Нажмите кнопку **«🚀 Настроить Telegram в 1 клик»**.
* Официальный Telegram Desktop откроет окно подтверждения: нажмите *«Включить»*.
* Все сообщения, медиа и звонки Telegram пойдут напрямую через защищённый локальный SOCKS5-прокси (порт `1080`).

### 2. Добавление своих сайтов (например, `rutor.info`)
* Перейдите на вкладку **«🌐 Мои сайты»**.
* **Глобальный режим (по умолчанию):** обход работает автоматически для **любых** сайтов (YouTube, GitHub, Rutor и др.). Ничего добавлять вручную не нужно.
* **Режим по списку:** если вы хотите применять фрагментацию пакетов только к избранным доменам, выберите переключатель *«Только сайты из списка»*, введите нужные домены (например, `rutor.info`) и нажмите **«💾 Сохранить список»**.

> **Совет для rutor.info и трекеров:** Включите в настройках браузера *«Безопасный DNS (DoH)»* (Cloudflare `1.1.1.1` или Google `8.8.8.8`), так как провайдеры часто блокируют трекеры подменой DNS.

### 3. Проверка доступности (Диагностика)
* На вкладке **«⚡ Главная»** нажмите **«Проверить сайты»**.
* Программа проверит прямой доступ к YouTube, GitHub, Telegram и Rutor.info и покажет отклик в миллисекундах.

### 4. Работа в системном трее (возле часов)
* При закрытии окна крестиком программа не выключается, а сворачивается в трей.
* Двойной клик по иконке в трее открывает окно.
* Правый клик по иконке вызывает быстрое меню (Включить / Выключить, Настроить Telegram, Выход).

### 5. Выбор движка
* **ByeDPI (по умолчанию, рекомендуется):** работает как локальный SOCKS5-прокси в пространстве пользователя. Не требует прав администратора и драйверов. Приложение само включает системный прокси Windows для браузеров.
* **GoodbyeDPI:** низкоуровневый системный перехватчик сетевых пакетов на базе драйвера WinDivert. Требует запуска от имени Администратора.

## 🛠 Пересборка из исходников

Если вы измените дизайн (`src\MainWindow.xaml`) или код (`src\*.cs`), пересобрать `DpiTunnel.exe` можно за 1 секунду с помощью скрипта:
```cmd
build.bat
```
Всё собирается встроенным в Windows компилятором .NET Framework без установки лишних программ.
